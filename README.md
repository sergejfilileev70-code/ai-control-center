# AI Control Center — MVP 0.1

Облачное веб-приложение для совместной работы OpenAI и Anthropic. Интерфейс на русском языке.

## Что уже работает

- Три режима: критическая проверка, параллельный анализ, последовательное улучшение.
- Отдельные ответы ChatGPT и Claude плюс итоговый синтез.
- API-ключи хранятся только в переменных окружения сервера.
- Простой пароль приложения через `APP_PASSWORD`.
- Health endpoint: `/api/health`.

## 1. Подготовка

Нужны:
- OpenAI API key: https://platform.openai.com/api-keys
- Anthropic API key: https://platform.claude.com/settings/keys
- GitHub-репозиторий для Render.

Создайте API-ключи в кабинетах провайдеров. Не вставляйте ключи в исходный код, чат, GitHub или браузер.

## 2. Локальный запуск (Windows PowerShell)

Установите Python 3.11+.

```powershell
cd ai-control-center
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и заполните `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `APP_PASSWORD`.
Задайте длинный уникальный пароль приложения. Приложение загрузит значения из `.env` автоматически. Запустите:

```powershell
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000

Для удобства можно использовать PowerShell-переменные как выше; не публикуйте терминальные логи и скриншоты с секретами. Для постоянной локальной конфигурации используйте менеджер секретов или загрузку `.env` через оболочку, не добавляя его в Git.

## 3. Развёртывание в Render

1. Создайте приватный GitHub-репозиторий.
2. Распакуйте проект и загрузите файлы в репозиторий.
3. В Render выберите **New → Blueprint** и подключите репозиторий с `render.yaml` (либо создайте Web Service вручную).
4. При запросе заполните три секретных значения: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `APP_PASSWORD`.
5. Убедитесь, что `OPENAI_MODEL` и `CLAUDE_MODEL` указывают на модели, доступные вашему API-аккаунту.
6. Дождитесь успешного Deploy и откройте выданный адрес `*.onrender.com`.

Render читает секреты из Environment; они не должны попадать в репозиторий. Для production используйте платный постоянно работающий сервис, а не рассчитывайте на бесплатный инстанс для непрерывной доступности.

## 4. Проверка

- Откройте `/api/health`: проверьте `openai_configured`, `claude_configured`, `app_password_configured`.
- В веб-интерфейсе введите пароль приложения.
- Отправьте тестовую задачу: «Назови три риска запуска нового интернет-магазина и способы их снизить».
- Проверьте, что появились два ответа и финальный синтез.

## 5. Важные ограничения MVP

- Пока нет регистрации пользователей, базы данных, постоянной памяти, загрузки файлов и истории диалогов.
- Пароль приложения — базовая защита для личного тестового стенда, не полноценная multi-user авторизация. Перед открытием для команды добавьте полноценные сессии, rate limiting, CSRF-защиту, аудит и изоляцию пользователей.
- Результаты моделей могут содержать ошибки. Не отправляйте автоматически финансовые, юридические или публичные действия без проверки.
- API оплачивается отдельно от потребительских подписок ChatGPT и Claude.
- Названия моделей вынесены в переменные окружения: если аккаунт не имеет доступа к указанной модели, поменяйте значение на доступный model ID.
